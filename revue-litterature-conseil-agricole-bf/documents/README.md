# Documents téléchargeables (accès libre)

Ce dossier accueille les textes intégraux **en accès libre** des documents de la fiche de lecture, rangés par niveau de pertinence. Les articles payants ne sont pas redistribués : leur lien vers l'éditeur figure dans la fiche Word.

Les PDF n'ont pas pu être téléchargés depuis l'environnement où le dépôt a été préparé, dont l'accès réseau était limité. Pour les récupérer, lancez depuis le dossier `revue-litterature-conseil-agricole-bf/` :

```bash
python3 scripts/telecharger_documents.py
```

Le script range chaque PDF dans le bon sous-dossier sous le nom indiqué ci-dessous. Quelques éditeurs (Taylor & Francis, Wiley, Cambridge) peuvent bloquer les téléchargements automatiques. Dans ce cas, ouvrez le lien dans un navigateur et enregistrez le PDF sous le nom attendu.
